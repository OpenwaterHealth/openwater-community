Licensing & the Open Commons

Licensing Framework

Openwater uses four license layers for different kinds of software, hardware and documentation. Check the LICENSE file in the repository you use for its current terms.

Current model

AGPL-3.0-or-later covers the reciprocal software core; Apache-2.0 covers permissive software and integrations; CERN-OHL-S-2.0 covers hardware reference designs; and CC-BY-4.0 covers documentation and sample data.

What each license covers

These are the approved classifications. A repository's current LICENSE governs its published contents until any rights-reviewed change is merged.

LayerLicenseExamples
Reciprocal software coreAGPL-3.0-or-laterOpenLIFU console and transmitter firmware; OpenMOTION FPGA/HDL; sensing, beamforming, reconstruction, signal-processing and calibration core
Permissive software and integrationApache-2.0OpenMOTION firmware; all bootloaders; 3D Slicer extensions; applications, tooling, SDKs, language bindings and scripts
Hardware reference designsCERN-OHL-S-2.0Mechanical CAD, schematics, PCB layouts and related design sources
Documentation and dataCC-BY-4.0Guides, tutorials, templates and sample data

The SlicerOpenLIFU extension and four active hardware repositories still carry AGPL license files. Their approved destination takes effect only after contributor rights are confirmed and the repository license is changed. Third-party components retain their own terms.
