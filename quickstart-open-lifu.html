Welcome to Open-LIFU

Open-LIFU is Openwater's programmable Low Intensity Focused Ultrasound platform — a console, transducer, desktop application, and Python SDK for steered LIFU research. This page is the single source of truth for getting started. Repositories, READMEs, and the device user manual all link here.

Path A · OpenLIFU-python

Clone → install → smoke test → load sample data.

Clone the repository

Fork first on GitHub, then clone your fork locally. New here? Hit the Fork button on the repo, then copy your fork's clone URL.

git clone https://github.com/<your-username>/OpenLIFU-python.git cd OpenLIFU-python git remote add upstream https://github.com/OpenwaterHealth/OpenLIFU-python.git
OpenLIFU-python on GitHub →

Create a virtual environment & install

Editable install picks up your code changes without reinstalling.

python -m venv .venv # macOS/Linux: source .venv/bin/activate # Windows: .venv\Scripts\activate pip install -e .

Smoke test

If this prints a version, you're good.

python -c "import openlifu; print(openlifu.__version__)"
✅ Working? You're ready to load sample data and start hacking.

Pull sample data and browse examples

The sample database lives in a separate repo and is fetched via Git LFS.

git lfs install git clone https://github.com/OpenwaterHealth/openlifu-sample-database # Then browse examples/ in OpenLIFU-python — load a transducer JSON, run a sim.

Path B · OpenLIFU-App & 3D Slicer

Desktop app for planning and running sonications, with a 3D Slicer extension for visualization.

Install the Open-LIFU Desktop Application

  1. Go to the latest release.
  2. Download the system-specific installer (.exe on Windows, .tar.gz on Linux). Approve the security warning if prompted.
  3. Run the installer.
⚠️ Windows path gotcha: The install path cannot contain spaces. The default folder includes a space after "OpenLIFU" — remove it. Also make sure your Windows username has no spaces (install elsewhere if it does).

First launch finishes installing dependencies before opening the home page.

Latest Release →

Install 3D Slicer & the OpenLIFU extension

  1. Install 3D Slicer matching the version listed in the latest OpenLIFU-App release notes.
  2. Open Extension Manager → search for "OpenLIFU" → install.
  3. Restart Slicer.

Open OpenLIFUHome and point at the sample database

  1. Open the OpenLIFUHome module.
  2. In OpenLIFUDatabase, point at your local clone of openlifu-sample-database.
  3. Sign in as example_admin.

Plan & simulate a sonication

  1. Open PrePlanning → pick a target.
  2. Open SonicationPlanner → simulate the sonication.
🎉 You just planned your first sonication. Now you're ready to contribute.

Make Your First Contribution

The fork → branch → commit → PR → CLA → merge loop.

The 5-minute first-PR loop

Don't overthink your first contribution. Pick one of these and ship it:

  • Docs fix — typo, broken link, unclear sentence in a README.
  • Unit test — add a missing test case for an existing function.
  • Sandbox experiment — a new example notebook in examples/.
git checkout -b fix/short-description # make changes git add . git commit -m "Docs: fix typo in transducer README" git push origin fix/short-description # then open a PR on GitHub
CLA: First PR triggers an automated CLA signature. Takes under 2 minutes.

Optional · Photogrammetry Add-ons

Only needed if you're running transducer-tracking workflows with the Android scanner.

Install Meshroom 2023.3.0

  1. Download Meshroom 2023.3.0 for Windows from alicevision.org/#meshroom.
  2. Extract the archive to a directory of your choice.
  3. Add the folder containing Meshroom.exe to your user PATH (Start menu → "Edit environment variables for your account" → User variables → Path → Edit → New).
  4. Optional GPU: NVIDIA Control Panel → 3D Settings → Manage 3D settings → Program Settings → add Meshroom.exe → set "High-performance NVIDIA processor".

Install Android Platform Tools (ADB)

Option 1: Download Google's platform-tools, extract, and add the folder containing adb.exe to your PATH. Verify with adb --version.

Option 2 (PowerShell):

Set-ExecutionPolicy RemoteSigned -Scope CurrentUser irm get.scoop.sh | iex scoop install android-platform-tools

Install the Android photogrammetry app

  1. On your Android phone, open OpenLIFU-3DScanner.
  2. Open Releases → pick the latest version → tap the .apk.
  3. Approve install. Open the app and allow camera and storage permissions.

Enable Developer Mode + USB Debugging

  1. Settings → About Phone → tap Build number 7 times.
  2. Settings → System → Developer options → enable USB debugging.
  3. Plug into your PC and check "Always allow" when prompted.
