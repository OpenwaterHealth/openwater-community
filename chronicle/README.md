# Generated Chronicle Site

Do not hand-edit files in this folder once the Chronicle build process is enabled.

In the next infrastructure step, source Markdown from `content/chronicle/` will be converted into:

- `/chronicle/index.html` — current issue + archive
- `/chronicle/<issue-slug>/index.html` — individual issue pages
- `/chronicle/feed.xml` — RSS feed consumed by HubSpot

For now, this README reserves the public output directory.
