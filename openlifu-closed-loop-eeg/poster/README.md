# Poster

The interactive web poster for this study, intended for publication via GitHub Pages.

Once the poster's static files (`index.html` and assets) are added here, enable GitHub
Pages for the repository (Settings → Pages → deploy from branch, `/poster` or the
repository root) to publish it at:

```
https://openwaterhealth.github.io/openlifu-closed-loop-eeg/
```

The poster is a submittable artifact for neuromodulation venues and open-source
conferences (e.g. Open Source Summit NA, OSHWA Open Healthware) — see the promotion plan
in the project notes.

> Poster source is migrated in with the original developer's work. Keep all public-facing
> text in the research-use register (subject, sonication, research use) per the
> [README disclaimer](../README.md) and [`../CONTRIBUTING.md`](../CONTRIBUTING.md).
