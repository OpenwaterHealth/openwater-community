Contribute Without a Unit

Most of our community will never receive a physical Openwater device, and that's fine. The platform is open-source — the highest-leverage work happens in code, documentation, quality, research methodology, and clinical workflow design. Five lanes. Two good-first-issues each. A named human on every lane. Pick one and ship.

Best for: Developers

Code

Ship Python, Slicer, and tooling improvements against simulators and fixtures. The MATLAB-to-Python migration is the highest-leverage place to start.

Good-first-issues
  • Port one MATLAB calibration utility to Python
  • Add starter database initialization options
Contact: community@openwater.health
Open Code issues
Best for: All roles

Documentation

Make the platform legible to the next contributor. Tutorials, glossaries, API docs, translations. Your work is the first thing a new arrival reads.

Good-first-issues
  • Write a "Day 1 with the repo" tutorial (no hardware needed)
  • Build a 30–50 term glossary of focused-ultrasound language
Contact: community@openwater.health
Open Document issues
Best for: Developers

Quality

Triage, reproduce, audit. The work that keeps the platform trustworthy as the community grows.

Good-first-issues
  • Triage and reproduce three open GitHub issues
  • Run an accessibility audit on the community hub
Contact: community@openwater.health
Open Quality issues
Best for: Researchers

Research

Build the shared knowledge base future trials will rely on. Literature synthesis, schemas, methodology.

Good-first-issues
  • Build a structured literature library of FUS papers, 2023–2025
  • Draft a safety-data schema RFC for community contributions
Contact: community@openwater.health
Open Research issues
Best for: Clinicians

Clinical

Shape the workflow future recipients of devices will follow. IRB templates, plain-language summaries, safety reporting.

Good-first-issues
  • Plain-language summary of the depression trial outcomes
  • Draft an IRB submission template section on open-source platform considerations
Contact: community@openwater.health
